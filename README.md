# LineTest releases

Installers and release notes for **LineTest**, a Windows desktop tool that tests an internet line (speed, latency, jitter, packet loss, path, PPPoE session) and produces a plain-English verdict and an ISP-ready PDF report.

Download the latest installer from the [Releases](https://github.com/RR-IsCool/LineTest-releases/releases) page. The installer runs per user without administrator rights and upgrades an existing installation in place.

The app checks this repository for new versions at startup and from Help, Check for updates.
